# FluxLedger

An original C++17/Python laboratory for separating physical and numerical
diffusion in periodic scalar transport. Compares first-order upwind and
monotonized-central MUSCL reconstruction with conservative face fluxes and
SSPRK3 time integration. Analytical cell averages, mass balance, pulse bounds,
and convergence studies will accompany the implementation.

Status: development scaffold. Not yet validated.

Topic provenance: local CFD course topics in numerical approximation,
time integration, and scheme analysis; CFD lab topic in unsteady 1D
advection-diffusion. Only directory/file names were used to select the topic.
No course text, solutions, exercise code, or datasets are included.
